# Independence from Chatterbox-TTS-UI: completion record

**Date:** 2026-11-02 · **Branch:** `refactor/independence-20261102` · **Issues:** #55, #57 · **Upstream:** `AcTePuKc/Chatterbox-TTS-UI` @ `22460fd99ceb78c309f879b93878240241a0dc9b` (MIT)

Sonic Rift began as a fork of Chatterbox-TTS-UI. The owner relicensed Sonic Rift under Apache-2.0 on 2026-10-31 and kept the upstream MIT notice for code still derived from it. This record covers the work that replaced that code, so the MIT notice no longer applies to the current tree. It is an engineering record, not legal advice.

## What was replaced

Every upstream file in the current tree was rewritten from a written description of its behaviour, with its own structure (different decomposition, control flow and data structures), not edited line by line. User-visible behaviour, settings keys and file formats were kept.

## Evidence

`scripts/audit_upstream_similarity.py` compares Sonic Rift with the upstream commit offline, and `tests/test_upstream_independence.py` runs it with the test suite so inherited code can't come back unnoticed.

| Measure | Before (2026-11-02, release branch) | After |
| --- | --- | --- |
| Upstream functions at ≥ 0.8 similarity to a Sonic Rift function | 47 of 95 | **0** |
| Upstream functions at 0.6–0.8 | 18 | 9, all 2–4 line Qt calls or unrelated code (e.g. a one-line `getattr`) |
| Highest similarity | 1.00 (many identical) | 0.73 |
| Upstream Python lines (≥ 30 characters) found verbatim | 606 | 51 |
| `setup_env.bat` / `setup_env.sh` lines also upstream | 159 of 163 / 99 of 103 | 21 of 130 / 2 of 88 |

The 51 remaining lines are public function and class names other code depends on (`def get_selected_model_entry(self):`), single Qt calls (`self.stop_button.setEnabled(False)`), model file names (`"v3": "t3_mtl23ls_v3.safetensors"`), the settings and model-list file names, and JSON keys fixed by the file formats. The remaining script lines are `@echo off`, `exit /b 1`, `set -euo pipefail` and similar.

Not code, and kept: `requirements.lock.txt` is generated by `uv pip compile` and lists package versions (facts); the `.all-contributorsrc` and README headings are tool configuration and generic section names.

## Verification

- Full test suite: 664 tests, OK (below-normal priority), plus the independence gate.
- Real window (off-screen, disposable profile): the real Chatterbox multilingual model loads (10 s on CUDA) and generates; the take plays, pauses, resumes, scrubs and stops; stopping a long render keeps the finished sections and its message; settings and window size are saved on close and restored. 17 of 17 checks.
- A copy of the owner's own `app_settings.json` and `models.json` loads with the new code: all 10 models and all 11 settings keys kept after a save.

## Notice decision

The current tree no longer contains copies or substantial portions of Chatterbox-TTS-UI, so the MIT notice no longer applies to it and was removed from `LICENSES/`. Commits up to this point in the repository's history still contain the upstream code together with its MIT license, as published. The README keeps a thank-you to the upstream authors as a courtesy, not as a license condition.

Optional engines (Resemble AI's Chatterbox TTS, Qwen3-TTS, Kokoro and others) are separate projects with their own licenses; this record doesn't change them.
